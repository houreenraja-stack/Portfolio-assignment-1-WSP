INFR2810U-Project

This project was for Computer Architecture, it implements a traffic light controller for a intersection as a finite state machine moving through one state to another through inputs, it controls 2 roads:North-South (NS) -- the main road, stays green default East-West (EW) -- the second road, get to turn on it when requested It also includes: an emergency override which forces all lights to go red from any state until the emergency clears How it works the controller is implemented in plain python langauge coding, with states as plain strings and constans and a 'step()' functions that controls the controller by one simulated second/tick.
